# 两数之和（Two Sum）

## Problem
给定一个整数数组 `nums` 和一个目标值 `target`，请在数组中找出和为 `target` 的**两个**整数，并返回它们的下标。可以假设每种输入**只对应一个答案**，且同一个元素不能重复使用。

## Constraints
```
2 <= len(nums) <= 10^4
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9
恰好存在一个有效答案
```

## Examples
| # | Input                          | Output   | Note                          |
|---|--------------------------------|----------|-------------------------------|
| 1 | nums = [2, 7, 11, 15], target = 9 | [0, 1]   | nums[0] + nums[1] = 2 + 7 = 9 |
| 2 | nums = [3, 2, 4], target = 6      | [1, 2]   | nums[1] + nums[2] = 2 + 4 = 6 |
| 3 | nums = [3, 3], target = 6         | [0, 1]   | 两个相同的值也可               |

## Knowledge Points
- 哈希表（Hash Map）

## Solution
- **直观思路**：双重循环枚举所有两两组合，检查是否等于 `target`，时间复杂度 O(n²)，`n` 达到 `10^4` 时约 `10^8` 次操作，偏慢，不是最优解。
- **最优解切入点**：固定当前元素 `x` 后，我们要找的另一个数就是**确定的** `target - x`。与其重新扫描数组去找它，不如**边遍历边把见过的数记进哈希表**，这样查找「是否见过 `target - x`」就变成 O(1)。
- **步骤**：
  Step 1. 建一个哈希表 `seen`，键为数值、值为其下标；
  Step 2. 遍历 `nums`，对每个 `x = nums[i]`，先查 `target - x` 是否已在 `seen` 中——在则直接返回两个下标；
  Step 3. 若不在，把 `x -> i` 存入 `seen`，继续遍历。
- **复杂度**：时间复杂度 O(n)，空间复杂度 O(n)。每个元素只入表一次、查表一次。

## AC Code
```python
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []


if __name__ == '__main__':
    print(twoSum([2, 7, 11, 15], 9))  # [0, 1]
    print(twoSum([3, 2, 4], 6))       # [1, 2]
    print(twoSum([3, 3], 6))          # [0, 1]
```
