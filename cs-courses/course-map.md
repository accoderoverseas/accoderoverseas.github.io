## 通用 CS 学习主线（先修脉络）

```
编程基础 → 数据结构与算法 ┬→ 操作系统 ─┐
                          ├→ 计算机网络 ─┼→ 分布式 / 系统设计
                          ├→ 数据库 ─────┘
              离散数学 ───┴→ 算法进阶 → 机器学习 / 人工智能 → 数据科学 / 大模型
```
