# 数据结构与算法 · 知识点速查

> **代表课程**：Data Structures & Algorithms（如 UNSW COMP2521 / UC Berkeley CS61B / CMU 15-122 …）
> 一页看清：核心知识点脉络 → 典型例题 → 参考资料。**持续更新**。

## 核心知识点总结

| 模块 | 关键概念 | 高频考点 / 易错点 |
|---|---|---|
| 复杂度分析 | 时间 / 空间、大 O / Ω / Θ、均摊分析 | 递归复杂度（主定理）、最坏 vs 均摊、隐藏常数 |
| 线性结构 | 数组、链表、栈、队列、双端队列 | 链表指针操作、栈/队列的模拟应用 |
| 树 | 二叉树、BST、平衡树（AVL / 红黑）、堆、Trie | 遍历（前/中/后/层序）、平衡旋转、堆化 |
| 图 | 表示（邻接表/矩阵）、BFS / DFS、最短路、MST、拓扑排序 | 建模、访问标记、Dijkstra vs Bellman-Ford 适用条件 |
| 排序与查找 | 快排、归并、堆排、计数/基数排序、二分查找 | 稳定性、原地性、二分边界 |
| 算法设计范式 | 分治、贪心、动态规划、回溯 | DP 状态定义与转移、贪心正确性证明 |

> 📝 *待补充*：结合你所在课程的大纲，细化各模块的重点与本课特有的考法。
