# 离散数学 · 知识点速查

> **代表课程**：Discrete Mathematics（如 MIT 6.042 / 各校 Discrete Math 课）
> 一页看清：核心知识点脉络 → 典型例题 → 参考资料。**持续更新**。

## 核心知识点总结

| 模块 | 关键概念 | 高频考点 / 易错点 |
|---|---|---|
| 逻辑 | 命题/谓词逻辑、量词、推理规则 | 真值表、逻辑等价、量词否定 |
| 证明方法 | 直接/反证/归纳法、鸽笼原理 | 数学归纳与强归纳、构造反例 |
| 集合与关系 | 集合运算、关系、等价关系、偏序 | 自反/对称/传递、等价类、哈斯图 |
| 函数 | 单射/满射/双射、复合、基数 | 可数 vs 不可数、对角线论证 |
| 组合数学 | 计数原理、排列组合、二项式、容斥 | 加法/乘法原理、隔板法、容斥公式 |
| 图论 | 图的基本概念、连通、欧拉/哈密顿、树 | 握手定理、二部图、生成树 |
| 数论 | 整除、模运算、GCD、同余、RSA 基础 | 欧几里得算法、逆元、费马小定理 |
