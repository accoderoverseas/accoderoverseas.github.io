# 计算机网络 · 知识点速查

> **代表课程**：Computer Networks（如 Stanford CS144 / 各校 Networking 课）
> 一页看清：核心知识点脉络 → 典型例题 → 参考资料。**持续更新**。

## 核心知识点总结

| 分层 | 关键概念 | 高频考点 / 易错点 |
|---|---|---|
| 概览 | 分层模型（OSI / TCP-IP）、封装、时延与吞吐 | 传播/传输/排队时延计算、带宽 vs 时延 |
| 应用层 | HTTP、DNS、SMTP、CDN、P2P | HTTP/1.1 vs 2 vs 3、DNS 解析流程、缓存 |
| 传输层 | UDP、TCP、可靠传输、流量/拥塞控制 | 三次握手/四次挥手、滑动窗口、AIMD、重传 |
| 网络层 | IP、路由、转发、NAT、ICMP | 子网划分/CIDR、最长前缀匹配、距离矢量 vs 链路状态 |
| 链路层 | 成帧、差错检测、MAC、以太网、ARP | CSMA/CD、CRC/校验和、交换机 vs 集线器 |
| 网络安全 | 对称/非对称加密、TLS、证书、防火墙 | 握手流程、中间人、常见攻击面 |

> 📝 *待补充*：结合你所在课程的大纲，标注本课重点与实验（如 CS144 的 TCP 实现）。
