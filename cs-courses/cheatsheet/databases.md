# 数据库 · 知识点速查

> **代表课程**：Databases（如 CMU 15-445 / 各校 DB 课）
> 一页看清：核心知识点脉络 → 典型例题 → 参考资料。**持续更新**。

## 核心知识点总结

| 模块 | 关键概念 | 高频考点 / 易错点 |
|---|---|---|
| 数据模型 | 关系模型、ER 图、键与约束 | ER → 关系映射、主键/外键/候选键 |
| 关系代数 | 选择、投影、连接、聚合 | 关系代数 ↔ SQL 互译 |
| SQL | 查询、连接、子查询、分组、窗口函数 | JOIN 类型、NULL 语义、GROUP BY / HAVING |
| 规范化 | 函数依赖、1NF–BCNF、分解 | 求闭包/候选键、无损分解、依赖保持 |
| 存储与索引 | 堆/顺序文件、B+ 树、哈希索引 | B+ 树增删、索引选择、聚簇 vs 非聚簇 |
| 事务 | ACID、隔离级别、并发控制、日志恢复 | 两阶段锁、可串行化、死锁、WAL / redo-undo |
| 查询处理 | 执行计划、连接算法、代价估计 | 嵌套循环/哈希/排序归并连接的取舍 |
