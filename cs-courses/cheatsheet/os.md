# 操作系统 · 知识点速查

> **代表课程**：Operating Systems（如 UNSW COMP3231 / MIT 6.1810 / 各校 OS 课）
> 一页看清：核心知识点脉络 → 典型例题 → 参考资料。**持续更新**。

## 核心知识点总结

| 模块 | 关键概念 | 高频考点 / 易错点 |
|---|---|---|
| 进程与线程 | 进程状态、PCB、上下文切换、线程模型 | 进程 vs 线程、用户级 vs 内核级线程 |
| CPU 调度 | FCFS、SJF、RR、优先级、多级反馈队列 | 周转/等待时间计算、饥饿与老化 |
| 并发与同步 | 临界区、互斥锁、信号量、条件变量、死锁 | 死锁四条件、生产者-消费者、读者-写者 |
| 内存管理 | 分页、分段、虚拟内存、页表、TLB | 地址翻译、缺页处理、内碎片/外碎片 |
| 页面置换 | FIFO、LRU、Clock、最优置换 | Belady 异常、命中率计算 |
| 文件系统 | inode、目录、分配方式、日志 | 硬/软链接、一致性与崩溃恢复 |
| I/O 与设备 | 中断、DMA、缓冲、磁盘调度 | SSTF / SCAN 调度、系统调用路径 |
