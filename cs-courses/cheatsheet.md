# CS课程速查

常见 CS 专业课程方向与核心主题速查（持续更新）。用于快速定位「这门课大概学什么、重点在哪」。

| 方向      | 代表课程 / 主题                        | 关键词                                 |
|---------|----------------------------------|-------------------------------------|
| 编程语言基础  | C/C++/Java/Python Programming | 基本语法、数据类型、变量、顺序/选择/循环结构、函数、递归、OOP 等 |
| 数据结构与算法 | Data Structures & Algorithms     | 数组、链表、栈和队列、树、图、查找、排序、复杂度分析等         |
| 离散数学    | Discrete Math                    | 逻辑、集合、组合数学、图论                         |
| 操作系统    | Operating Systems                | 进程/线程调度、内存管理、文件系统等                  |
| 计算机网络   | Computer Networks                | 分层模型、TCP/IP、路由                      |
| 数据库     | Databases                        | 关系模型、SQL、事务、索引                      |
| 计算机系统   | Computer Systems / Architecture  | 汇编、内存层次、并发                          |
| 软件工程    | Software Engineering             | 需求、设计、测试、协作                         |
| 机器学习    | Machine Learning                 | 监督 / 无监督、评估、过拟合                     |
| 人工智能    | Artificial Intelligence          | 搜索、约束、概率推理                          |
| 数据科学    | Data Science / Statistics        | 数据处理、可视化、统计推断                       |

> 需要针对某门课出**定制大纲**（预习 / 复习 / 项目 / 考前复盘）？→ [联系我](/contact/)。
