# 示例 · UNSW COMP2521：从挂科边缘到 HD

<div class="case-figph">📌 <b>本页是「案例模板」示例</b>，用于展示案例的组织方式与图文排版；正式内容将替换为<b>真实、匿名、经学生同意</b>的案例（含真实截图）。<b>不承诺保过</b>，结果受个人投入、市场与运气影响。</div>

## 学生背景（匿名）
- **学校 / 课程**：UNSW · `COMP2521` Data Structures & Algorithms
- **起点**：期中偏低；链表 / 图"一写就错"，典型的"看题解会、自己写不出"
- **目标 / 时间线**：期末前约 5 周，冲 Credit 以上

## 痛点诊断
- 数据结构停留在"背概念"，没建立 **"接口 → 实现 → 复杂度"** 的心智模型
- 图算法（BFS / DFS / 最短路 / MST）遇到就慌，代码结构混乱
- 调试全靠猜，不会用**不变量 + 画内存图**定位 bug

## 辅导方案（一步步怎么带）
1. **抓关键知识点、搭知识体系**：先和学生一起画一张 COMP2521 知识地图（模块 → 关键概念 → 典型考点），锁定 **"图 + 复杂度分析"** 为重点投入区。
   <div class="case-figph">🖼️ 配图位：知识体系思维导图（放真实截图前先给敏感信息打码）。</div>
2. **精讲 + 手写实现**：每个结构都"接口 → 实现 → 复杂度"过一遍，坚持**手写实现**而非套模板。
   <div class="case-figph">🖼️ 配图位：手写笔记 / before-after 代码对比截图。</div>
3. **陪练 + 纠错**：限时做题 → 我现场 review → 定位坏习惯 → 当场改。
4. **考前冲刺**：按高频考点做专题 + 模拟卷，逐题复盘错因。

## 关键知识点抓手
- 图的两种表示 + BFS / DFS **模板化**；最短路 / MST 的适用条件
- 复杂度分析：从"能背"到**"能推"**
- 调试方法论：**不变量 + 画内存图**

## 结果（示例）
- 期末 <span class="case-badge">Fail 边缘 → HD（示例）</span>；更重要的是"能独立写出并给别人讲清"。
- 学生反馈（匿名，示例）：「第一次觉得图论不再是玄学，考前心里有底了。」
